# Tesla-GME-Stock-Analysis
An exploratory data analysis project using Python to extract, process, and visualize historical stock prices and quarterly revenue for Tesla (TSLA) and GameStop (GME). Utilizes yfinance, Requests, BeautifulSoup, Pandas, and Matplotlib.
# Tesla and GameStop Stock Price & Revenue Analysis

## Project Overview

This project explores historical stock price data and quarterly revenue for Tesla (TSLA) and GameStop (GME) using Python.

The analysis focuses on extracting financial data, cleaning datasets, and visualizing historical stock performance alongside quarterly revenue trends.

## Objectives

- Extract historical stock price data using the Yahoo Finance API.
- Retrieve quarterly revenue data from financial webpages.
- Perform web scraping using Requests and BeautifulSoup.
- Clean and organize financial datasets using Pandas.
- Visualize historical stock prices and quarterly revenue trends.
- Compare stock market performance with company revenue.
